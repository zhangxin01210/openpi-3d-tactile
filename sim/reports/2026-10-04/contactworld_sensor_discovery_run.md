# ContactWorld USB 双指触觉、视觉与动作分析：一键运行

在仓库根目录执行：

```bash
bash sim/scripts/launch_contactworld_sensor_discovery.sh
```

命令会在后台启动 CPU 任务并打印 PID、日志和报告位置。随后可用：

```bash
tail -f /home/sai/zx/openpi-sim-runtime/runs/contactworld_sensor_discovery_20261004/launch.log
```

看到 `REPORT .../index.html` 和 `DONE` 后打开：

`/home/sai/zx/openpi-sim-runtime/runs/contactworld_sensor_discovery_20261004/index.html`

脚本逐条缓存示范特征，重新执行同一命令会跳过已完成的示范和探针。后台任务使用输出目录的文件锁，避免两次启动同时写入。若需新输出目录，可在命令前设置 `CW_DISCOVERY_OUTPUT=/path/to/new/output`。

## 报告里看什么

报告**先展示原始案例**：同帧前视 RGB、腕视 RGB、左右触觉预览，以及左右指各自 base Fx/Fy/Fz 六张有符号力图。所有案例固定使用训练集力值 P99.5 色标。策略回放未保存触觉预览 MP4，因此对应位置显示从原始局部三分量力场计算的幅值伪彩图，并明确标注。案例图附原视频链接、插头相对插座的位置和下一步动作。

案例包含正/负 Fz、偏向不同方向、未接触/已接触、触觉改善/损害留出动作预测、视觉相似却调整方向相反，以及 40 个配对初态中 RGB 与点云+触觉策略结果相反的两组对照。

之后看图表：力的方向与插头偏移、Fz 符号与前一步运动、局部坐标与 base 坐标的关系、接触前后时间曲线、接触后动作和物理状态的留出预测。网页下方提供逐配置的数值表和 CSV/JSON 下载。`fit/test_metrics.csv` 有比网页表格更多的条件分组。

## 实验口径

- 输入来自已确认的双指 LeRobot V3 导出及原仿真回放；**不会再仿真采集**。数据为 95 条 train、15 条 val、10 条 test。所有划分按完整示范，测试轨迹不用于训练或选参。
- RGB 特征使用本机已缓存的冻结 ResNet18，取双视图全图与固定中心裁剪，再用训练示范拟合的 128 维 PCA 压缩；裁剪不使用插座真值。触觉保留左右指、原始局部三通道、base 三维力和位置，力场 PCA 只在训练集拟合。
- 轻量岭回归探针对比状态、RGB、Fz、Fx/Fy、每指粗统计、完整力场及短时历史；预测下一步示范动作、插头相对插座 XY、插座接触和已知动作后的四步运动。插座真值、接触判据及未来动作**只作标签或事后分析**，不进入预测输入。
- “插座接触”使用 U 盘—插座仿真合力 `>0.1`，与指尖受力不是一回事。帧 `f` 是执行当前动作前的观测；帧 `f−1` 的仿真接触力对应这一观测。方向以插座坐标系定义；所展示的 Fx/Fy/Fz 力图以机器人 base 坐标系定义，报告还单独比较传感器局部分量。
- 描述性相关会列帧数和独立示范数，预测结果在未参与训练和选参的 10 条测试示范上计算。报告对关键动作误差差值按示范重采样给区间。10 条独立测试示范无法支持很细的亚组结论；原始案例用于解释和查找反例，单例不用于宣称总体规律。
- 40 初态 × 13 策略的已有评测只用于挑选少数配对可视化案例；这些策略动作不当作示范真值。完整策略成功率仍见已有 `analysis.json` 和 `diagnosis/index.html`。

小规模完整流程已在 6 train、2 val、2 test 上跑通，生成了原始传感器案例图、六张统计图、留出探针、报告和 CSV。也逐项检查了全量 120 条示范所需的回放、双视图视频与双指空间力文件，缺失数为 0。全量运行预计主要花在逐帧视觉特征提取；无需 GPU、网络或下载。
